## Project Overview

This project examines employee attrition at Frito Lay using statistical analysis and machine learning as part of my Master of Science in Data Science program at Southern Methodist University.

The analysis explores factors associated with employee turnover, including overtime, job involvement, work-life balance, and employee tenure.

## Tools and Methods

- R and RStudio
- Exploratory Data Analysis
- Chi-Square Tests
- K-Nearest Neighbors (KNN)
- Naive Bayes Classification
- Data Visualization
